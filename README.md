# 福袋助手（Android）

一个本机运行的 Android 无障碍自动化示例，仅针对抖音包名 `com.ss.android.ugc.aweme`。

## 功能
- 开关控制是否监测。
- 监听抖音窗口变化。
- 查找文本/无障碍描述中包含：福袋、参与福袋、领取福袋、超级福袋、粉丝福袋。
- 找到后点击最近的可点击父控件。
- 900ms 点击冷却，避免连续触发。
- 不读取密码、不处理验证码、不绕过平台风控。

## 构建
需要 JDK 17+、Android SDK Platform 35、Build Tools 35.x。

```bash
gradle assembleDebug
```

输出：`app/build/outputs/apk/debug/app-debug.apk`

## 安装后
1. 打开“福袋助手”。
2. 点“打开无障碍设置”。
3. 找到“福袋助手”并允许。
4. 返回应用，打开“开始监测福袋”。
5. 打开抖音直播间。

## 注意
抖音 UI 可能随版本变化；如果控件未暴露无障碍文本，本版本不会采用坐标盲点或验证码/风控绕过手段。
